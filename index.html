Oct 2026 – PresentSolidity · TypeScriptMonad Metropolis Hackathon

Anvay

Gasless claim-link remittance protocol on Monad

  • Send dollars home with a link: the sender locks AUSD in an EIP-712 escrow contract, shares the link on WhatsApp, and the recipient collects it with zero gas and no wallet setup.
  • Designed the security model so link keys never leave the browser (URL fragment only), each signature binds to a single transfer ID to block replay, and the relayer cannot redirect funds anywhere except the address named in the signature.
  • Integrated a Chainlink CRE oracle workflow for live USD→INR rates, Envio HyperIndex for on-chain event indexing, and WebAuthn PRF passkey accounts with HKDF-derived per-link keys.
  • Shipped 35 Foundry tests covering front-running, replay, signature malleability, expiry and fuzz cases, tested against Agora's real AUSD on a mainnet fork.

Jan 2026 – PresentPython SDKOpen source

Loom-Protocol

Agent Transfer Protocol for secure multi-agent handoffs

  • Designed and open-sourced a protocol with a 3-layer security model, so one agent can pass work to another without the message being forged or replayed.
  • Built an atomic ledger for distributed multi-agent state, so a handoff either fully commits or rolls back, with an audit trail across agent pipelines.
  • Built a Python SDK with sync and async clients. Azure-native mode uses Cosmos DB for the ledger, Entra ID for identity and Content Safety for policy enforcement.
  • Python
  • asyncio
  • Azure AI Foundry
  • Cosmos DB
  • Entra ID

Multi-model AI orchestration and RAG pipeline for financial queries
